01 · 联合输出训练：完整目标与真实基线分开

H1 · 当前段联合输出RL 训练

验证列表是否学会，同时看正文质量。输出块成功不等于关键词集合正确。

<src=English><tgt=English> <VERBATIM> asked jean valjean fauchelevent replied <keywords> fauchelevent

H2 · 下一段识别是否改善冻结模型评估

用完全相同的新模型比较无反馈与预测反馈。真实闭环不读取 reference、当前 GT 或未来 GT。

K̂(t) → history → bias hint(t+1) 只影响下一段，不能回头修改第 t 段 无反馈 A2 ↔ 预测反馈 A3：配对比较

02 · 连续识别：session 内串行，session 间并行

prev_only：先验证最小闭环

H(t) 由第 t 段预测列表生成；空块/坏块清空。第一段不带关键词。候选词用模型已有 biasing 格式传入下一段。

历史词自洽不代表正确：幻觉正文和列表可能同时包含一个错误词。必须用随机无关词压力测试、插入错误指标和 history 过期机制检查错误传播。

正文和列表分开报告

各数据集分别给出 WER/CER、列表 P/R/F1/exact、协议成功率、空目标假阳性、截断率；反馈额外检查 B-WER/U-WER、插入数与重复词子集。

可靠性与资源成本

同音频同 checkpoint 配对，按 chapter bootstrap 95% CI；记录提示 token、时延/RTF、session 串行吞吐。若 A3 未优于 A2，则反馈收益未证实。

06 · 里程碑：每一步都有进入条件

P0 → P2 · 数据与协议

本轮方案与审计 → 冻结 common5k、speaker split、去重复文本、音频检查 → prompt/GT/parser round-trip 与旧任务兼容。

P3 → P4 · 无反馈 pilot

Reward sanity 排序和 GT/baseline 隔离 → 训练小规模 pilot → dev 验证 H1，检查 KL、advantage 与正文质量。

P5 → P6 · 闭环和正式测试

冻结模型，加入 prev_only 与可恢复 wave scheduler → 因果性测试 → 固定参数后报告 internal 与 official 的 A2/A3/A5/A6。

P7 · 可选反馈适配

只有发现 biasing 与新输出的组合瓶颈时，再讨论 past-prediction hints 训练。第一版不默认引入多步 RL 或跨段奖励。
