7. Experimental Fully-Async Concurrency and Backpressure

Dataset Prefetch worker thread

  • _feed_samples() owns the continuous DataLoader iterator.
  • asyncio.to_thread(_next_sample) overlaps audio decode/blob I/O with generation.
  • A DataLoader lock prevents checkpoint state capture from racing iterator advancement.
RLHFDataset.__getitem__ → collate_fn → prepare_single_generation_data → pending_queue.put(RolloutSample)

Rollouter Backpressure Ray actor

  • pending_queue is the bounded prefetch buffer.
  • active_tasks cannot exceed max_concurrent_samples.
  • Staleness or pause signals drain active work and gate new submissions.
while active_tasks ≥ max_concurrent_samples: await FIRST_COMPLETED safe_create_task(_process_single_sample_streaming(...))

Worker Dispatch Ray RPC

  • FullyAsyncAgentLoopManager picks one worker round-robin.
  • AgentLoopWorker.generate_sequences() creates one asyncio task per DataProto row.
  • asyncio.gather() joins per-row agent outputs.
worker.generate_sequences.remote(prompts) → _run_agent_loop(...) → SingleTurnAgentLoop.run(...)

Inference Fan-out GPU replica

  • FullyAsyncLLMServerClient acquires a replica through the global load balancer.
  • vLLM continuously batches concurrent requests.
  • Abort/resume logic can continue partially generated requests around policy synchronization.
server_manager.generate(...) → server.generate.remote(...) → engine.generate(TextPrompt, SamplingParams)
